## Introduction
Functions are one of the most important building blocks in programming.
They let you package a piece of logic once and reuse it anywhere in
your code. In this lesson, you will learn what functions are, how to
define them, and why they make your programs easier to read and
maintain.

## Section: What Is a Function?
A function is a named, reusable block of code that performs a specific
task. Instead of repeating the same instructions every time you need
them, you write the logic once inside a function and call it whenever
required. Functions can accept inputs, called parameters, and can
return an output using the `return` keyword.

## Section: Defining a Function in Python
In Python, a function is defined using the `def` keyword, followed by
the function name and a set of parentheses containing any parameters.
The body of the function is indented beneath the definition line. For
example, `def greet(name): return f"Hello, {name}!"` defines a simple
function that takes one parameter and returns a greeting string.

## Section: Why Functions Matter
Functions make code easier to test, debug, and reuse. By isolating a
single responsibility inside each function, you reduce duplication and
make it simpler to reason about what each part of your program does.
This is the same principle of separation of concerns that guides good
software architecture at every scale, from a single function to an
entire application.

## Conclusion
Functions are the foundation of clean, maintainable Python code. As you
continue learning, you will build on this concept with parameters,
default values, and more advanced patterns like recursion and
higher-order functions.
